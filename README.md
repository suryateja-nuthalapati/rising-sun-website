# Rising Sun — Static Website

## Files
- `index.html` — website content
- `style.css` — responsive styling
- `assets/rising-sun-logo.jpg` — uploaded logo
- `assets/rising-sun-emblem.jpg` — emblem crop used for favicon/header

## Before publishing
1. Replace `hello@yourdomain.com` in `index.html` with your real business email.
2. Edit the About/Business text to match your actual company activities.
3. If you want, replace the logo JPG with a transparent PNG/SVG later.

## GitHub Pages
Upload the files to a GitHub repository, then enable:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

For a custom domain, add the domain under:
Settings → Pages → Custom domain.

Then configure DNS at your domain provider. See the official GitHub Pages documentation for the exact DNS values.
